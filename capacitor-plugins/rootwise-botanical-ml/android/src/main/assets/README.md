# Required model assets

The Android plugin becomes locally operational only after both of these artifacts are supplied by the model owner:

- `botanical_mobilenetv4_512d.tflite`
- `botanical_reference_embeddings.json`

The embedding catalog must be generated by the exact installed model version and contain traceable source IDs. See the plugin README for the complete schema and tensor contract.

These assets are deliberately not fabricated or replaced with random starter vectors. Until they are supplied and validated, the plugin reports `ready: false` and the existing app uses its existing remote analysis path.
